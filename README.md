# Sophia Girls' Academy Website

Official website for Sophia Girls' Academy, a nonprofit organization dedicated to empowering girls through education, mentorship, and academic opportunities.

## Features

- Responsive design
- Resource library with search and filters
- Dynamic articles loaded from JSON
- Team page generated from JSON
- Summer Program information
- Contact form
- Mobile-friendly layout

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- JSON
- Font Awesome
- Google Fonts

## Running Locally

Clone the repository:

```bash
git clone https://github.com/jomotola/SophiaGirlsAcademy.git
```

Open the project with VS Code and run it using Live Server.

## Deployment

The website is deployed using Netlify.

Every push to the main branch automatically redeploys the website.
